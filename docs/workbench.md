
# 工作台

在 Windows 完成安装后，双击 [start-workbench.vbs](../start-workbench.vbs) 后台启动，浏览器会自动打开。再次打开同一工作区时会复用正在运行的服务。使用 [start-workbench.cmd](../start-workbench.cmd) 或在项目根目录运行 `.\.venv\Scripts\gaid.exe ui` 可查看终端日志。 [安装方法](../README.md#安装)

在 Linux 或 macOS 上，从项目根目录运行 `./.venv/bin/gaid ui`。工作台会使用 PyTorch 检测到的设备。 [ROCm 和 MPS 安装](accelerators.md)

## 打开、对比和导出

1. 点「打开」、把图片拖入画布或粘贴图片。原图会先显示，后台用默认设置生成成品 B。从「近期」选择或再次打开同一张图会恢复草稿。
2. 在「成品检查」拖动分割线，比较原图和 B。在画布下方点「固定为对照 A」后，画布上方可让左侧在原图和固定的 A 之间切换，右侧显示当前成品 B。滚轮缩放，按住空格拖动画布，按住 `X` 暂看整张原图。
3. 最新 B 显示后，点「导出 PNG」保存原尺寸图片。旁边的菜单也可导出固定方案 A。设置了导出目录时，工作台直接保存并显示路径，点提示中的「在文件夹中显示」即可定位到刚保存的 PNG。使用浏览器下载时，可在浏览器的下载记录中定位文件。

## 处理模式

- **整图降噪**处理全图的可见像素。纯 L0 无需下载模型，仍可调线条保护和渐变恢复。点「降噪效果」或按 `F` 打开参数，可以边调边看分割对比。
- **按部位精修**需要[分区模型](models.md)。点「编辑流程」可单独调整部位、选区和降噪效果。
- 点画布上方右侧的模式名称切换。草稿记住当前模式，部位和选区的编辑会保留。从整图切到精修时，如果还没有对照 A，工作台会把上一次完成的整图成品固定为 A。

## 编辑流程

「编辑流程」显示当前图片的原图、分区、处理范围、全图降噪预览和成品。点进节点后，左侧选工具，画布上方选动作，右侧选部位或参数。用顶部标签可直接切换编辑节点，点「流程」回到总览。

| 节点 | 用法 |
| --- | --- |
| 部位分区 | 在「分区叠加」中，用画笔、套索、磁性套索或 SAM2 改归属。待确认默认可改，其他分区默认受保护。袖口被错认成头发时，先点「头发」旁的小锁解锁，再选「服饰」修正。要把一块头发移到待确认，选「头发」和「移出当前部位」，直接画选这块即可。「擦除本步修改」可恢复原有归属。 |
| 处理范围 | 在「实际处理」中勾选参与降噪的部位，再按需调整各部位强度。用「加入处理范围」补选，用「移出处理范围」在局部保留原图。「局部减弱」按比例减少降噪，「指定原图比例」直接设置原图混合比例。「擦除本步修改」恢复这一步的自动范围。 |
| 降噪效果 | 选择整张图的降噪算法和整体强度。用「全图降噪预览」查看算法直接生成的图。展开高级设置可调 L0、预缩放、线条保护和渐变恢复等适用参数。「恢复内置默认值」会恢复本图的降噪算法、整体强度和高级参数。 [参数说明](cli.md#常用参数) |
| 成品 B | 按当前缩放和平移位置回到成品检查。 |

- 部位分区和处理范围的「原图 / 成品」用分割线对比原图和当前 B。在对比和改动视图中可缩放、平移和查看记录。回到「分区叠加」或「实际处理」可继续编辑，按住 `X` 暂看原图时会暂停绘制。
- 拖动工具栏手柄可把工具放在画布上。拖回停靠边缘或点击手柄即可停靠。桌面停靠在左侧，窄窗停靠在上方。工具栏浮动时，聚焦手柄后可用方向键移动。
- 在「分区叠加」里，用右侧列表的眼睛单独显示或隐藏各部位、背景、外物和待确认。隐藏处会露出原图，可继续用画笔和套索修边。
- 列表顶部「全部分区」的眼睛可全部显示或隐藏，锁可全部锁定或解锁。部分开启时，点击对应的总开关会全部开启。
- 「实际处理」右侧的「参与处理」表把部位勾选、强度和手动锁放在同一行，表头的锁可一键操作全部分区。画笔、套索、SAM2、反选和按部位恢复会跳过已锁部位，每次操作记录当时的锁定状态。
- 按住 `Ctrl` 点击部位名称，只显示该部位的叠加。对同一部位再次按住 `Ctrl` 点击，恢复之前的显隐组合。
- 按 `B` 选画笔并沿用当前动作。按住 `Shift` 在画布上滚动，向上放大画笔，向下缩小。`[` 和 `]` 也可微调，单步变化为原图上的 2 px 直径。
- 在处理范围中还可调羽化宽度，内圈内完全生效，两圈之间逐渐减弱。分区画笔使用清晰边界。处理范围可用 `I` 补入、`D` 移出、`P` 减弱、`M` 指定原图比例、`E` 擦除本步修改。部位分区可用 `C` 归入目标部位，`D` 移出当前部位。
- 新的补选笔画按笔径缩小自动边缘过渡，过渡宽度最多为笔刷半径的三分之一，并受图片的默认过渡宽度限制。相连的笔画会平滑衔接。早期的固定过渡笔画按保存时的规则回放。
- 「实际处理」的颜色从浅青、蓝紫到玫红，依次表示处理从弱到强。
- 用「套索」`L` 或「磁性套索」`G` 沿边缘落点。磁性套索会自动落下小圆点，单击可落下方形锚点。按住 `Alt` 画直线，按 `Backspace` 撤回上一锚点。点回起点或按 `Enter` 闭合，按 `Esc` 放弃。
- 按 `S` 选「SAM2 点选」，在想选中的区域添加目标点，轮廓越界时加排除点。在画布上按 `Enter` 生成预览，核对后再次按 `Enter` 应用。想标记外物时，在部位分区选「外物」作为目标。
- 黑白斜纹表示待确认区域，默认保留原图。可在「部位分区」给它指定部位，或在「处理范围」明确允许补选。完全透明的像素保持原状。
- 笔迹立即显示。松笔、闭合套索或应用 SAM2 选区后，先更新分区图或权重图，再在后台生成成品 B。可用 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。分区和范围各有修改记录，可定位本节点的笔画。
- 「分区改动」与自动识别的分区对比，用改动后的部位颜色标出净变化。移到待确认的像素显示黑白斜纹。「范围改动」以当前分区和设置生成的自动范围为基准，标出手动造成的补入、移出和权重变化。左下角图例显示当前画面中的颜色和含义。

## 快捷键速查

点状态栏「快捷键」或按 `?` 查看完整列表。

| 操作 | 快捷键 |
| --- | --- |
| 打开、粘贴、导出当前可见的成品 B | `Ctrl+O`、`Ctrl+V`、`Ctrl+S` |
| 暂看原图、切换左侧原图 / 固定 A | 按住 `X`、`A` |
| 适合窗口、1:1、放大、缩小 | `0`、`1`、`+` 或 `=`、`-` |
| 编辑流程或整图降噪参数、成品检查 | `F`、`R` |
| 移动、画笔、套索、磁性套索、SAM2 | `H`、`B`、`L`、`G`、`S` |

## 工作台设置

- **新图默认值**可设处理模式、算法、参与部位和强度。「自动选择」有分区模型时用按部位精修，否则用整图降噪。也可固定用指定模式。选择按部位精修但缺少模型时，工作台会提示并用整图降噪打开新图。
- 选「每次选择」后，导入新图会先显示原图，选择模式后开始处理。重新导入有草稿的图片时，菜单会标记「上次使用」的模式。打开「近期」中的草稿会沿用已选模式。
- **导出与缓存**设置 PNG 导出位置，查看分析缓存的实际路径和占用。工作台空闲时，「释放中间缓存」可移除旧版留下的诊断图、推理中间数据和过期候选，保留恢复编辑所需的分区和降噪候选。「清空分析缓存」会移除这些可重算数据，下次编辑时重新分析。原图、草稿、对照 A 和近期记录保存在 `outputs/workbench/`。
- **工作台**可切换主题、记住画笔直径和羽化，以及设置关闭页面时的行为。偏好保存在本机，重启后继续使用。

在设置中点「退出工作台」会保存当前草稿、关闭后台并关闭当前页面。浏览器限制关页时，页面会显示退出提示，你可以手动关闭标签页。

默认关闭网页会保留后台。打开「设置 → 工作台」中的「关闭最后一个工作台页面时退出后台」，最后一页关闭几秒后，后台会自动停止，刷新页面会继续连接。

后台启动日志保存在 `outputs/workbench/workbench.log`。使用终端启动时，也可按 `Ctrl+C` 退出。

## 与命令行共用校正

在节点编辑页打开「导出 PNG」旁的菜单，选「导出命令行校正」。工作台会给出 `corrections.json` 的保存位置，将它传给 `--edits` 即可复用。校正文件采用二值蒙版。羽化、随笔径调整的过渡、局部原图比例、软保护和分部位强度等连续权重保存在工作台草稿中。仅补选的待确认区域需先指定部位才能导出校正。 [命令行说明](cli.md#应用校正)

用同一张源图打开工作台后，可选「导入命令行校正」，同时选择二值校正 JSON 与其引用的 PNG 蒙版。包含 SAM 点提示的校正由命令行处理。
