
# 工作台

在 Windows 安装并准备模型后，双击 [start-workbench.vbs](../start-workbench.vbs) 后台启动，浏览器会自动打开。再次打开同一工作区时会复用正在运行的服务。使用 [start-workbench.cmd](../start-workbench.cmd) 或在项目根目录运行 `.\.venv\Scripts\gaid.exe ui` 可查看终端日志。 [安装方法](../README.md#安装)

## 打开、对比和导出

1. 点「打开」、把图片拖入画布或粘贴图片。原图会先显示，后台用默认设置生成成品 B。从「近期」选择或再次打开同一张图会恢复草稿。
2. 在「成品检查」拖动分割线，比较原图和 B。点「固定当前成品为对照 A」，左侧会保留这一版，右侧显示后续调整。滚轮缩放，按住空格拖动画布，按住 `X` 暂看原图。
3. 最新 B 显示后，点「导出 PNG」保存原尺寸图片。旁边的菜单也可导出固定方案 A。设置了导出目录时，工作台直接保存并显示路径，否则交给浏览器下载。

## 编辑流程

「编辑流程」显示当前图片的原图、分区、处理范围、全图降噪预览和成品。点进节点后，左侧选工具，画布上方选动作，右侧选部位或参数。

| 节点 | 用法 |
| --- | --- |
| 部位分区 | 在「分区叠加」中，用画笔、套索、磁性套索或 SAM2 改归属。待确认默认可改，其他分区默认受保护。袖口被错认成头发时，先点「头发」旁的小锁解锁，再选「服饰」修正。要把一块头发移到待确认，选「头发」和「移出当前部位」，直接画选这块即可。「擦除本步修改」可恢复原有归属。 |
| 处理范围 | 勾选参与降噪的部位，再按需改各部位强度。用「加入处理范围」补选，用「移出处理范围」在局部保留原图。「局部减弱」按比例减少降噪，「指定原图比例」直接设置原图混合比例。「擦除本步修改」恢复这一步的自动范围。 |
| 降噪效果 | 选择整张图的降噪算法和整体强度。用「全图降噪预览」查看算法直接生成的图。展开高级设置可调 L0、预缩放、线条保护和渐变恢复等适用参数。 [参数说明](cli.md#常用参数) |
| 成品 B | 按当前缩放和平移位置回到成品检查。 |

- 部位分区的「原图 / 成品」用分割线对比原图和当前 B。按住 `X` 可暂看整张原图。
- 选「画笔」`B` 后可调直径。在处理范围中还可调羽化宽度，内圈内完全生效，两圈之间逐渐减弱。分区画笔使用清晰边界。处理范围可用 `D` 移出、`P` 减弱、`M` 指定原图比例、`E` 擦除本步修改。
- 用「套索」`L` 或「磁性套索」`G` 沿边缘落点。磁性套索会自动落下小圆点，单击可落下方形锚点。按住 `Alt` 画直线，按 `Backspace` 撤回上一锚点。点回起点或按 `Enter` 闭合，按 `Esc` 放弃。
- 用「SAM2 点选」在想选中的区域添加目标点，轮廓越界时加排除点。点「生成预览」检查轮廓，再确认应用。想标记外物时，在部位分区选「外物」作为目标。
- 黑白斜纹表示待确认区域，默认保留原图。可在「部位分区」给它指定部位，或在「处理范围」明确允许补选。完全透明的像素保持原状。
- 笔迹立即显示，结果在后台更新。可用 `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。在「手动修改记录」可定位笔画，再用「手动改动」核对与自动起点的差异。

## 工作台设置

- **新图默认值**设置算法、参与部位及整体和分部位强度。可以把当前图的处理参数存为默认，已有草稿会继续使用各自的参数。
- **导出与缓存**设置 PNG 导出位置，查看分析缓存的实际路径和占用。更换目录或清理缓存时需等待工作台空闲。原图、草稿、对照 A 和近期记录保存在 `outputs/workbench/`。
- **外观与画笔**支持浅色、深色和跟随系统，可记住画笔直径和羽化。偏好由本机应用保存，重启工作台后可继续使用。

在设置中点「退出工作台」会保存当前草稿并关闭服务。后台启动日志保存在 `outputs/workbench/workbench.log`。使用终端启动时，也可按 `Ctrl+C` 退出。

## 与命令行共用校正

在节点编辑页打开「导出 PNG」旁的菜单，选「导出命令行校正」。工作台会给出 `corrections.json` 的保存位置，将它传给 `--edits` 即可复用。校正文件采用二值蒙版。羽化、局部原图比例、软保护和分部位强度等连续权重保存在工作台草稿中。仅补选的待确认区域需先指定部位才能导出校正。 [命令行说明](cli.md#应用校正)

用同一张源图打开工作台后，可选「导入命令行校正」，同时选择二值校正 JSON 与其引用的 PNG 蒙版。包含 SAM 点提示的校正由命令行处理。
