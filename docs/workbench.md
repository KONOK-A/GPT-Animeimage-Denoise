# 工作台

按 [README](../README.md#使用) 安装并准备模型后，双击 [start-workbench.cmd](../start-workbench.cmd)，或在项目根目录运行 `.\.venv\Scripts\gaid.exe ui`。如果浏览器没有自动打开，访问终端打印的地址。

## 打开、对比和导出

1. 点「打开」、把图片拖入画布或粘贴图片。原图会先显示，默认结果在后台生成。
2. 在「看成品」拖动分割线，比较原图和成品 B。要对比两种调法，点「固定当前成品为对照 A」，再继续调整 B。
3. 单击「导出 PNG」保存更新完成的 B，或从旁边的菜单导出固定方案 A。导出使用原图尺寸。

鼠标滚轮缩放，按住空格拖动画布，按住 `X` 暂看原图。编辑会自动保存，从「近期」可接着做。数据保存在 `outputs/workbench/`，可在终端按 `Ctrl+C` 关闭工作台服务。

## 改处理范围

进入「改哪里」。默认选皮肤、面部和头发。要处理其他部位或背景，在「自动选区起点」勾选对应项。也可选「从空范围」自己画，或从「整图」开始缩减范围。

| 想做什么 | 工具 |
| --- | --- |
| 补一块漏选区域 | 「画入」`B` |
| 让一块区域保留原图 | 「移出」`D` |
| 降低已选区域的去噪强度 | 「局部减弱」`P` |
| 指定某处混入多少原图 | 「原图比例」`M`。填 `70%` 时，已选区域的笔刷中心混合 70% 原图和 30% 降噪候选 |
| 擦掉一处手动标记，交回自动选区 | 「擦改动」`E` |
| 沿轮廓一次圈出一块区域 | 「套索」`L` 或「磁性套索」`G` |

套索先在右侧选「圈选动作」，再沿边缘落点。磁性套索从边缘单击起步，沿轮廓移动会自动落下小圆点，也可单击落下方形锚点。按住 `Alt` 画直线，按 `Backspace` 撤回上一锚点。两种套索都可点回起点或按 `Enter` 闭合，按 `Esc` 放弃。

### 修正待确认和外物

- **待确认**默认保留原图，在「识别部位」和「实际处理」用黑白斜纹显示。普通画入跳过待确认时，右侧会给出像素数。用「加入这笔的处理范围」直接补选，或者点「归为所选部位」将该区域归入指定部位。
- **已识别外物**用橙色显示，默认保留原图。误判时，可以用套索的「纠正误判」恢复为人物部位，也可以选择画入或套索的「加入处理范围」，勾选「允许补选模型建议保留的区域」。
- **外物漏检**时，选「点选外物」，在道具上加「目标点」，在紧贴道具的手套、袖口上加「排除点」。点「生成预览」核对轮廓，再点「标为外物」将它移出处理范围。

### 核对已生效的修改

- **识别部位**看模型与人工修正后的类别。若有「疑似外物」视图，琥珀色提示可核对的区域，原部位仍可照常编辑。
- **实际处理**看最终混入多少降噪候选。蓝色越深，处理越强。
- **手动改动**对照同设置下的自动起点，显示哪里新增、移出、增强、减弱或改了部位。右侧可定位最近操作。「B 已包含」表示这次操作已计入计算，实际变化以图层为准。

选区操作可按 `Ctrl+Z` 撤销或 `Ctrl+Shift+Z` 重做。局部减弱和移出等标记即使当前没有可见变化，也可能在之后选入该部位时生效。

## 调整降噪效果

在「调效果」换算法、调整体强度，原有选区和笔画会继续使用。只想轻一点可以点「强度 65%」。使用含 L0 的算法时，点「L0 0.001」可加重平滑。线条保护、渐变恢复和预缩放等参数在「高级设置」，「恢复标准」可重置效果参数。参数含义见 [命令行](cli.md#常用参数)。

## 与命令行共用校正

在「导出 PNG」旁的菜单选择「导出命令行校正」。工作台会给出 `corrections.json` 的保存位置，将它传给 `--edits` 即可复用。校正文件采用二值蒙版，局部原图比例、软保护和分部位强度保存在工作台草稿中。只解锁且未归类的待确认像素需先指定部位才能导出校正。 [命令行说明](cli.md#应用校正)

用同一张源图打开工作台后，可选「导入命令行校正」，同时选择二值校正 JSON 与其引用的 PNG 蒙版。包含 SAM 点提示的校正由命令行处理。
